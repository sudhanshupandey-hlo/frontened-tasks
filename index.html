ABOUT THE PROJECT

Built with responsive-first thinking.

This project demonstrates how a webpage can adapt its layout and content to different viewport sizes.

The structure uses semantic HTML and the styling uses CSS Grid, Flexbox, relative units and media queries.

WHAT I DO

Responsive development essentials

The following areas demonstrate the main techniques used in this project.

01

Flexible Layouts

CSS Grid and Flexbox create layouts that automatically adjust to available space.

02

Media Queries

Breakpoints change columns, spacing, navigation and typography for smaller screens.

03

Fluid Elements

Relative units and max-width containers help content scale without unnecessary overflow.
